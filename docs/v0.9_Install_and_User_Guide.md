## 2. Before you start

- Use **desktop Excel for Windows** (Microsoft 365). The macros don't run in Excel for the web or in Excel for Mac.
- Your SharePoint sign-in (Organizational Account) must work, as it does for v0.8. Load Project refreshes data from SharePoint.
- **Don't** open or save the workbook in LibreOffice, Google Sheets, Excel for the web, or Excel on a phone or tablet. Saving it there can remove the Power Query connections.
- Check the file first: its SHA-256 is in `README_FIRST.txt` (PowerShell: `Get-FileHash <file>`).
- **If Excel says it found a problem and offers to repair the file, click No and report it.** Don't save a repaired copy.
- Work on a **local copy** first, for example in Documents. Move it to SharePoint only after testing.

## 3. Install the macros (once, about 10 minutes)

### Step 1: Unzip and unblock
1. Unzip the package into a folder, e.g. `Documents\CashFlow_v0.9\`.
2. Right-click `..._v0.9_working.xlsm` and choose **Properties**.
3. If you see **"This file came from another computer…"**, tick **Unblock** and click **OK**. Without this, Windows blocks the macros.

### Step 2: Open the workbook
1. Double-click the `.xlsm` to open it in desktop Excel.
2. If a yellow bar says **Enable Content**, click it.
3. If a red bar says macros are blocked, close Excel, go back to Step 1 and unblock the file.

### Step 3: Open the VBA editor
1. Press **Alt + F11**. The Visual Basic editor opens.
2. If you can't see the **Project** pane on the left, press **Ctrl + R**.

### Step 4: Import the three modules
1. Click **File → Import File…**.
2. Go to the unzipped `vba` folder, choose **`modTimeline.bas`** and click **Open**.
3. Repeat for **`modStore.bas`** and **`modSetup.bas`**.
4. In the Project pane, under **Modules**, you should now see `Module1` (already there), `modTimeline`, `modStore` and `modSetup`.

> Don't double-click the `.bas` files in Windows, and don't copy and paste them. Use **File → Import File…**.

### Step 5: Add the Workbook_Open code
1. In the Project pane, open **Microsoft Excel Objects** and double-click **ThisWorkbook**. An empty code window opens.
2. Open `vba/ThisWorkbook_code.txt` in Notepad. Copy the three lines from `Private Sub Workbook_Open()` to `End Sub`.
3. Paste them into the ThisWorkbook code window.

> Don't use Import for this file. Importing would create a separate module instead of adding the code to ThisWorkbook.

### Step 6: Compile (check for errors)
1. In the VBA editor, click **Debug → Compile VBAProject**.
2. **If nothing happens, that's good**: there are no errors.
3. If a message appears and a line turns yellow or blue, note the module name, the highlighted line and the message. Send them to me and stop here.

### Step 7: Run the one-off setup
1. Close the VBA editor (or press Alt + F11 again).
2. In Excel, press **Alt + F8**, choose **`Setup_Dashboard_v09`** and click **Run**.
3. You should see **"Setup complete."**
4. Four buttons now sit on `Main_Dashboard` at E8:F11: **Load Project**, **Save Projections**, **Re-assign unmatched** and **Delete unmatched**.

### Step 8: Save and reopen
1. Click **File → Save**. Keep the **.xlsm** format; if Excel asks about the macro-free format, choose **No**.
2. Close Excel and reopen the file, enabling content. This switches on the quarter +/− buttons for the protected sheet.

Installation is done.

## 4. Using the dashboard

### Load a project
1. On `Main_Dashboard`:
   - set **C6** to *Financial Year* or *Calendar Year*;
   - pick the **Source Project** in **E6**;
   - pick the **Main IO** in **F6**.
2. Check that **G6** says **Ready**.
3. Click **Load Project**. It refreshes the five selected-project tables (a few seconds), checks they all show your project, and builds the timeline from row 21.
4. **E7** shows "Dashboard loaded by <you> at <time>". The KPI cards (Budget, Actual to Date, Projected Total, Utilisation) now fill in.

### Read the timeline
- **Columns:**
  - Line, IO·Code, Budget;
  - then each month, with a **quarter total** after each quarter;
  - then the **FY totals** (or CY totals), then **Project Total**.
- **Collapse a quarter:** use the **−** / **+** above the column letters. You can also use the **1** / **2** buttons at the top left to collapse or expand every quarter.
- **Blocks:** MP, OM, EQ, CO and OTHER. Each block ends with **Projected**, **Actual**, **Variance ($)** and **Variance (%)**. The **PROJECT TOTAL** rows are at the bottom.
- **Variance** = Actual − Projected; a positive figure means overspend. It's shown only up to the **Latest SOA Month** (C9), so future plans don't look like underspend.
- **Grey MP rows,** e.g. `RA (Projected)`, are manpower projections (FTE × rate). They come from the manpower sheet and **can't be typed in**.

### Type projections
- Type monthly amounts in the **yellow cells**, which are the OM, EQ, CO and OTHER budget lines. Only numbers are accepted; negatives are allowed.
- A **blank** cell means no projection. **0** is saved as 0.
- Patient reimbursement goes on its OM budget line, like any other amount.

### Save
- Click **Save Projections**. Only this project's saved amounts are replaced.
- If you switch project with unsaved changes, Excel asks **"Save changes to … first?"**:
  - **Yes** saves;
  - **No** discards the changes;
  - **Cancel** stays on the current project.
- If someone else saved this project after you loaded it, you're asked whether to **overwrite** their save.
- If you changed E6/F6 without clicking Load Project, saving is blocked with **"Selection changed — reload first"**.

### Unmatched rows
Italic rows starting **"Unmatched:"** hold saved amounts that no longer fit the grid. This happens when:
- a budget line was renamed or removed in SOA;
- a line now nets to $0; or
- a month falls outside the project dates.

These amounts still **count in the totals**.
- **Re-assign:** click a cell in the Unmatched row, click **Re-assign unmatched**, then click any cell in the budget line that should get the amounts.
- **Delete:** click a cell in the Unmatched row, then click **Delete unmatched** and confirm.

### Charge a manpower line to another category (admin)
- On the **Dashboard_Settings** sheet, add a row to the table with:
  - Source Project, Main IO;
  - Rate Category, e.g. `AHS`;
  - the manpower IO Code, e.g. `TF25HIP136MP`;
  - **Charge To** (MP, OM, EQ, CO or OTHER).
- The next Load moves that line into that block as a locked row.

## 5. What changed from v0.8

- The old fixed timeline, the Manual Projection table, the Patient Reimbursement table and the C5 Project Display Name selector are retired.
  - A full copy of the v0.8 dashboard is kept on a hidden sheet, **Legacy_Timeline**, for comparison during testing. To view it: right-click any sheet tab → **Unhide** → Legacy_Timeline.
- The KPI cards now read the new timeline totals.
- The manpower table and sheet keep their v0.8 names, **`qManpower_SelectedTest`** / **`PQManpower_SelectedTest`**. If you want them renamed to match the other selected-test tables, do it in Excel (Table Design → Table Name; right-click the sheet tab → Rename), never by editing the file, and ask for the VBA constant `MANPOWER_TABLE` to be updated.
- New sheets: **Dashboard_Settings**, and the hidden **ProjectionStore**, which holds the saved projections.
- No Power Query query or connection was changed.

## 6. Troubleshooting

| What you see | What to do |
|---|---|
| Macros are disabled or the buttons do nothing | Close Excel, unblock the file (Step 1), reopen and click Enable Content. |
| "Setup Status is …" | Pick E6 and then F6 again until G6 shows Ready. If the project isn't in the list, use Data → Refresh All. |
| "Refreshing … failed" | Check your SharePoint sign-in (Data → Get Data → Data Source Settings), then try again. The timeline is left unchanged. |
| "… shows X, not Y" | The tables hold another project. Click Load Project again. If it repeats, use Data → Refresh All. |
| A compile error at Step 6 | Send me the module, the highlighted line and the message. |
| Excel says the sheet is protected | That's expected for totals and labels. Type only in the yellow cells. |
| The +/− outline buttons don't work | Save, close and reopen the file with content enabled. |
